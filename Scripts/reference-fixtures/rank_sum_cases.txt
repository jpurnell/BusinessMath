# Rank-sum distribution reference cases, read by generate_rank_sum.py and generate_rank_sum.R.
#
# One case per block: a `case <name>` line, then one line per judge with that judge's
# values for every wine, space-separated. Blocks end at a blank line. Values may be
# averaged ranks or raw scores: the generator re-ranks within each judge with
# `scipy.stats.rankdata` (average method, ascending), so an already-ranked row is unchanged
# and a score row becomes the averaged ranks the Swift tests then feed to
# `rankSumDistribution`. Which direction a score is ranked in does not matter here: the
# null distribution depends only on each judge's multiset of ranks, not on which wine got
# which rank.
#
# The larger panels (Monte Carlo, timing) are built in generate_rank_sum.py from a fixed
# seed rather than written out here.
