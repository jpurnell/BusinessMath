# Integer Programming

Get **exact solutions to discrete optimization problems** using branch-and-bound and branch-and-cut with LP relaxation, intelligent branching, and cutting plane generation.

All examples in this document are **playground-ready**, **numerically stable**, and **mathematically feasible**.  
They are written to work directly with the `BranchAndBoundSolver` implementation included at the end of this file.

---

## Overview

This module adds **integer and mixed-integer programming (IP / MIP)** to BusinessMath. It enables exact optimization for problems where decisions must be discrete:

- Project selection and capital budgeting
- Resource allocation and knapsack problems
- Facility location (linear, capacity-feasible form)
- Production planning with setup costs
- Portfolio construction with integer lots

The solver:
- Uses LP relaxations to compute valid bounds
- Branches on fractional variables
- Prunes by infeasibility, bounds, and integrality
- Guarantees optimality when `status == .optimal`

## IntegerProgramSpecification

Explicitly specifies which variables are integer or binary.

```swift
// All binary
let spec = IntegerProgramSpecification.allBinary(dimension: 5)

// Mixed
let spec = IntegerProgramSpecification(
    integerVariables: [0, 1],
    binaryVariables: [2, 3, 4]
)

// Utilities
spec.isIntegerFeasible(solution, tolerance: 1e-6)
let branchIndex = spec.mostFractionalVariable(solution)
```

## Usage Examples (Playground-Ready)

### Example 1: 0–1 Knapsack (Canonical)

```swift
import BusinessMath

let values  = [10.0, 15.0, 12.0]
let weights = [5.0, 7.0, 6.0]
let capacity = 10.0

let objective: @Sendable (VectorN<Double>) -> Double = { x in
    -zip(values, x.toArray()).map(*).reduce(0, +)
}

let constraints: [MultivariateConstraint<VectorN<Double>>] = [
    .linearInequality(coefficients: weights, rhs: capacity, sense: .lessOrEqual)
] + (0..<3).flatMap { i in
    [
        .inequality { x in -x[i] },
        .inequality { x in x[i] - 1.0 }
    ]
}

let result = try BranchAndBoundSolver<VectorN<Double>>().solve(
    objective: objective,
    from: VectorN([0.5, 0.5, 0.5]),
    subjectTo: constraints,
    integerSpec: .allBinary(dimension: 3),
    minimize: true
)

print(result.formattedDescription)
```

### Example 2: Capital Budgeting with Dependencies

```swift
import BusinessMath

let npv    = [80, 120, 100, 90, 200].map(Double.init)
let cost   = [200, 250, 220, 180, 300].map(Double.init)
let budget = 970.0

let objective: @Sendable (VectorN<Double>) -> Double = { x in
    -zip(npv, x.toArray()).map(*).reduce(0, +)
}

var constraints: [MultivariateConstraint<VectorN<Double>>] = [
    .inequality { x in zip(cost, x.toArray()).map(*).reduce(0, +) - budget }
]

// Dependencies
constraints += [
    .inequality { x in x[1] - x[0] },
    .inequality { x in x[2] - x[0] },
    .inequality { x in x[4] - x[1] },
    .inequality { x in x[4] - x[2] }
]

// Binary bounds
constraints += (0..<5).flatMap { i in
    [.inequality { x in -x[i] }, .inequality { x in x[i] - 1 }]
}

let result = try BranchAndBoundSolver<VectorN<Double>>().solve(
    objective: objective,
    from: VectorN(repeating: 0.5, count: 5),
    subjectTo: constraints,
    integerSpec: .allBinary(dimension: 5),
    minimize: true
)

print(result.formattedDescription)
```

### Example 3: Facility Location (Feasible Linear Form)

```swift
import BusinessMath

let fixedCosts = [50_000, 60_000, 55_000].map(Double.init)
let capacities = [300, 350, 400].map(Double.init)
let demands    = [100, 150, 120, 180, 140].map(Double.init)

let transport = [
    [10,15,20,12,18],
    [12,10,15,20,14],
    [18,12,10,15,10]
].map { $0.map(Double.init) }

let dimension = 3 + 15

let objective: @Sendable (VectorN<Double>) -> Double = { v in
    var cost = 0.0
    for i in 0..<3 { cost += fixedCosts[i] * v[i] }
    for i in 0..<3 {
        for j in 0..<5 {
            cost += transport[i][j] * v[3 + i*5 + j]
        }
    }
    return cost
}

var constraints: [MultivariateConstraint<VectorN<Double>>] = []

// Demand ≥
for j in 0..<5 {
    constraints.append(.inequality { v in
        demands[j] - (0..<3).map { v[3 + $0*5 + j] }.reduce(0,+)
    })
}

// Capacity
for i in 0..<3 {
    constraints.append(.inequality { v in
        (0..<5).map { v[3 + i*5 + $0] }.reduce(0,+) - capacities[i] * v[i]
    })
}

// Bounds
constraints += (0..<dimension).map { .inequality { v in -v[$0] } }
constraints += (0..<3).map { .inequality { v in v[$0] - 1 } }

let result = try BranchAndBoundSolver<VectorN<Double>>().solve(
    objective: objective,
    from: VectorN(repeating: 0.1, count: dimension),
    subjectTo: constraints,
    integerSpec: IntegerProgramSpecification(binaryVariables: [0,1,2]),
    minimize: true
)

print(result.formattedDescription)
```

### Example 4: Production Planning with Setup Costs

```swift
import BusinessMath

let productionCosts = [25, 30, 20, 28].map(Double.init)
let setupCosts      = [500, 600, 450, 550].map(Double.init)
let demands         = [100,150,80,120].map(Double.init)
let capacities      = [200,250,150,200].map(Double.init)

let objective: @Sendable (VectorN<Double>) -> Double = { v in
    (0..<4).map { productionCosts[$0]*v[$0] }.reduce(0,+)
  + (0..<4).map { setupCosts[$0]*v[4+$0] }.reduce(0,+)
}

var constraints: [MultivariateConstraint<VectorN<Double>>] = []

for i in 0..<4 {
    constraints.append(.inequality { v in demands[i] - v[i] })
    constraints.append(.inequality { v in v[i] - capacities[i]*v[4+i] })
}

constraints += (0..<8).map { .inequality { v in -v[$0] } }
constraints += (4..<8).map { .inequality { v in v[$0] - 1 } }

let result = try BranchAndBoundSolver<VectorN<Double>>().solve(
    objective: objective,
    from: VectorN(repeating: 0.0, count: 8),
    subjectTo: constraints,
    integerSpec: IntegerProgramSpecification(
        integerVariables: [0,1,2,3],
        binaryVariables: [4,5,6,7]
    ),
    minimize: true
)

print(result.formattedDescription)
print("Integer quantities:", result.integerSolution)
```

## Branching Strategies

### Most Fractional (Default)
- Fast, simple
- Best for small problems or prototyping

### Pseudo-Cost (Recommended)
- Learns which variables improve bounds
- Best default for production use

### Strong Branching
- Solves temporary LPs to choose best branch
- Expensive but minimizes tree size
- Best for small, high-value problems

## Nonlinear Integer Programming (MINLP)

Use a nonlinear relaxation solver when objectives or constraints are nonlinear.

```swift
let solver = BranchAndBoundSolver<VectorN<Double>>(
    relaxationSolver: NonlinearRelaxationSolver()
)

let objective: @Sendable (VectorN<Double>) -> Double = { x in
    x[0]*x[0] + x[1]*x[1]
}

let constraints: [MultivariateConstraint<VectorN<Double>>] = [
    .inequality { x in x[0]*x[0] + x[1]*x[1] - 1.0 }
]

let result = try solver.solve(
    objective: objective,
    from: VectorN([0.5, 0.5]),
    subjectTo: constraints,
    integerSpec: .allBinary(dimension: 2)
)

print(result.integerSolution)
```

## Best Practices

- Always include explicit bounds for binary variables
- Avoid equality constraints unless mathematically required
- Start with LP relaxation to test feasibility
- Use `pseudoCost` branching for most problems
- Check `status` and `relativeGap` before trusting results
