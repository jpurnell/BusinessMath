# Incoming test reviews

Raw reviews as received, before validation. **Nothing here has been checked against the code.**

A review is worked only after validation, and validation has never yet left one unchanged — every
review validated so far has been accurate in substance and wrong in at least one detail that
changed the fix. Treat a claim here as a hypothesis with a reference value attached.

`../TEST_REVIEW_ROADMAP.md` carries the validated findings, the corrections, and the plan. When a
review is fully validated it moves to `../proposals/REVIEW_<domain>_tests.md` with its corrections
folded in, joining the distribution, simulation and statistics reviews already there.
